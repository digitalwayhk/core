# v1.4.1：补齐内嵌前端编译产物

## 问题与修复

发布 v1.4.0 后从官方 Go 模块代理实际下载，发现 `pkg/server/run/dist/mock/fake_analysis_chart_data.json` 未在 Git 中提交：根目录 `*.json` 规则忽略了这个 22264 字节的编译产物。本地 dist 含 42 个资源文件及 build-info，实际模块缺少其中一个资源；其余文件字节一致，主界面和 Go 构建正常，但模块内容不能匹配 build-info 的 artifact_sha256。

本补丁只提交已经存在的该编译 JSON，并增加 dist JSON 的忽略例外。不修改前端源码、Go 源码、依赖、数据库或权限逻辑，也不重写 v1.4.0 标签。推荐消费方锁定 v1.4.1，功能迁移要求继续按[升级指南](UPGRADE_FROM_V1_3.md)执行。
